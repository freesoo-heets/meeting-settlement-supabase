STEP 29 - 관리자 회원 비밀번호 재설정

기능
- 회원 현황에서 닉네임 클릭 → 회원 상세 → 로그인 계정 관리
- 관리자/제작자가 허용된 회원의 새 비밀번호를 직접 재설정
- 기존 비밀번호는 표시/조회하지 않음
- 새 비밀번호 + 확인 입력, 6~72자 검증
- 실제 변경은 서버 API에서 SUPABASE_SERVICE_ROLE_KEY를 사용
- 비밀번호 문자열은 activity_logs에 기록하지 않음

권한
- 일반회원: 사용 불가
- 관리자: 일반회원 비밀번호 재설정 가능
- 관리자: 다른 관리자/제작자 비밀번호 재설정 불가
- 제작자: 일반회원 및 관리자 비밀번호 재설정 가능
- 제작자 계정: 회원관리 화면에서 재설정 불가
- 본인 계정: 기존 '내 계정'에서 직접 변경
- 최초 가입 전 회원(profile 없음): 재설정 불가

DB 변경 없음
환경변수 변경 없음
기존 SUPABASE_SERVICE_ROLE_KEY 사용
