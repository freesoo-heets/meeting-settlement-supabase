STEP 31 - UX/UI Polish

반영 내용
1. 모바일 하단 메뉴
- 기존 6개 3x2 메뉴를 홈/모임/회원/더보기 4개 핵심 메뉴로 변경
- 더보기 Bottom Sheet: 월별 참석 현황, 변경 이력, 사용방법, 내 계정
- 데스크톱 6개 상단 메뉴는 유지

2. 모임 관리 진행 흐름
- 선택 모임 아래 ① 참석자 → ② 비용 입력 → ③ 정산 공유 Stepper 추가
- 참석 인원, 비용 입력 여부를 즉시 확인 가능
- 기존 정산 기능/데이터 구조는 변경하지 않음

3. 회원 카드 관리 메뉴
- 카드에 여러 관리 버튼을 나열하던 구조를 ⋯ 메뉴로 정리
- 회원 상세 / 탈퇴·복귀 / 닉네임 변경 / 입장일 변경 / 관리자 지정·해제 / 삭제
- 기존 권한 조건 유지
- 비밀번호 재설정은 회원 상세의 로그인 계정 관리에서 유지

4. Toast
- 기존 notice를 화면 상단 고정 Toast 형태로 개선
- 닫기 버튼 추가

5. Empty State
- 회원 검색/필터 결과가 없을 때 안내 카드 + 필터 초기화 버튼

6. 디자인
- 모바일 Bottom Sheet, Stepper, 회원 ⋯ 메뉴 디자인 추가
- 카드/메뉴 간격과 계층을 정돈

DB 변경 없음
환경변수 변경 없음
PWA 캐시 v17

- 기능/권한/RLS 자체는 변경하지 않음
- 전체 npm run build는 패키지 환경이 없어 수행하지 못했으며 TS 문법 계열 점검 수행
