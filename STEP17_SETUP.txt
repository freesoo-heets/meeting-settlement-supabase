STEP 17 적용 순서

변경사항
- 선입금 표시는 "모임 관리 > 비용 배분"에서만 표시
- 대시보드, 내 현황, 월별 현황, 모임 상세에서는 선입금 표시 제거
- "남은 부담금" 명칭을 "벙비 합계"로 변경
- 벙비 합계는 선택 월의 해당 회원 배분금 총합 기준
- 모임명/날짜 수정 기능 추가
- 모임 삭제 기능 추가 + 삭제 확인창
- 모임 삭제 시 FK cascade에 의해 참석/게스트/비용배분/해당 모임 선입금도 함께 삭제
- 모임 비용을 기존 특정값 합계보다 낮게 수정하지 못하도록 안전장치 추가
- 최근 변경 이력 20건 추가
  · 모임 생성/복사/수정/삭제
  · 비용 수정
  · 회원 탈퇴/복귀
  · 입장일 수정
  · 관리자 지정/해제
- 변경 이력 UI는 일반회원/관리자/제작자 모두 동일하게 표시

적용 방법
1) Supabase SQL Editor에서 먼저 실행
   supabase/step17_activity_logs.sql

2) 아래 파일 덮어쓰기
   app/page.tsx
   app/globals.css

3) 서버 재시작
   Ctrl + C
   Remove-Item -Recurse -Force .\.next -ErrorAction SilentlyContinue
   npm run dev

새 환경변수는 없습니다.
