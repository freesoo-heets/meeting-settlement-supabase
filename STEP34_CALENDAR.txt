STEP 34 - 벙 달력 + 개인회원 참석 달력

모임 관리
- 월간 '벙 달력' 추가
- 날짜별 모임명 표시
- 같은 날 여러 벙 지원
- 날짜 우측 배지에 해당 날짜 벙 개수 표시
- 한 날짜 최대 3개 모임명 표시, 초과 시 +N개 더
- 달력의 모임 클릭 시 기존 모임 선택/관리 영역과 연동
- 이전달/다음달/이번달 이동
- 오늘 날짜 강조

회원 상세
- 개인 회원 '참석 달력' 추가
- 해당 회원이 실제 attendeeIds에 포함된 모임 날짜만 표시
- 날짜별 참석 모임명 표시
- 같은 날 복수 참석 지원
- 참석 모임 클릭 시 모임 상세 열기
- 이전달/다음달 이동
- 기존 최근 참석 10건 목록도 유지

모바일
- 달력은 날짜 정보를 억지로 찌그러뜨리지 않고 달력 내부 가로 스크롤 허용
- 페이지 자체 가로 스크롤은 발생하지 않도록 패널 내부에서 처리

DB/SQL 변경 없음
환경변수 변경 없음
PWA v22
