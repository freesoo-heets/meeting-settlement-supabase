STEP 32 - 회원 생일 + 대시보드 생일자

1. 회원 정보
- members.birthday date 컬럼 추가
- 기존 회원은 birthday NULL 상태로 유지
- 회원 카드에 생일 MM.DD 표시
- 회원 상세에 생일 표시

2. 최초 가입
- 최초 가입 폼에 생일 입력 추가 (필수)
- 신규 회원 생성 시 birthday 저장
- 관리자가 미리 추가해둔 기존 회원이 최초 가입하는 경우에도 입력한 생일을 기존 회원 정보에 저장
- 미래 날짜 입력 차단

3. 관리자
- 회원 추가 시 생일 선택 입력 가능
- 회원 카드 ⋯ 메뉴 → 생일 변경
- 생일 수정 또는 미입력(NULL) 처리 가능
- 변경 이력에는 날짜 변경 사실만 기록

4. 대시보드
- 인기벙 TOP3 / 이번 달 참석 TOP5 / 이달의 생일자 3개 카드 구성
- 이달의 생일자는 선택된 월 기준
- 활동중 회원만 표시
- 생일 날짜순 정렬
- 대시보드에서는 연도 없이 MM.DD만 표시
- 생일자 클릭 시 회원 상세

필수 SQL
Supabase SQL Editor에서 STEP32_BIRTHDAY_MIGRATION.sql 실행:
alter table public.members add column if not exists birthday date;

DB 변경: birthday 컬럼 1개 추가
환경변수 변경: 없음
