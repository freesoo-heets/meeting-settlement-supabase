STEP 27 - 모임 중심 대시보드

대시보드 개편
- 회원 중심 요약 제거
- 이번 달 모임 관련 핵심 수치 중심으로 재구성
- 모임 횟수 / 총 참석 / 참여 회원 / 총 벙비 카드
- 모임별 참석 규모를 막대 형태로 시각화
- 모임 행 클릭 시 해당 모임을 선택한 상태로 모임 관리 이동
- 비용 입력 현황 진행률 표시
- 비용 미입력 건 클릭 시 해당 모임으로 이동

관리 필요
- 대시보드의 '관리 필요'를 하나의 큰 버튼으로 변경
- 클릭하면 회원 현황 메뉴로 이동
- 회원 필터를 자동으로 '경고' 상태로 설정

이번 달 운영 통계
- 대시보드에서 제거
- 모임 관리 상단에 간소화된 '이번 달 운영 요약'으로 이동
- 모임 / 총 참석 / 참여 회원 / 총 벙비 4개 항목만 표시
