STEP 33 - 회원 추가/검색 레이아웃 + 회원상태 집계

회원 현황 레이아웃
- 관리자 화면: 회원 추가와 회원 검색을 데스크톱에서 좌/우 카드로 배치
- 좁은 화면/모바일: 자동 1열 배치
- 회원 추가 입력: 닉네임 / 입장일 / 생일 / +회원추가
- 회원 검색: 검색 / 정렬 / 상태 필터를 한 카드에 정리
- 390px 이하에서 상태 버튼은 2x2

회원 상태 집계
- 전체 = 활동중(정상) + 경고
- 탈퇴 회원은 전체 인원에서 제외
- 활동중 숫자는 경고가 아닌 활동중 회원만 집계
- 경고 숫자는 기존 경고 기준의 활동중 회원
- 탈퇴 숫자는 별도 유지
예: 정상 활동중 24명 + 경고 4명 + 탈퇴 3명
→ 전체 28명 / 활동중 24명 / 경고 4명 / 탈퇴 3명

필터 동작도 숫자와 일치
- 전체: 탈퇴 제외
- 활동중: 경고 제외 정상 활동중만
- 경고: 경고 회원만
- 탈퇴: 탈퇴 회원만
