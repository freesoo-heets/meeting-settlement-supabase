STEP 16 - UX 개선

추가 기능
1. 모임 상세 팝업
   - 최근 모임 또는 등록된 모임의 '상세' 버튼
   - 참석자/게스트/총비용/개인 부담금 확인
   - 상세 팝업에서 바로 모임 관리 화면으로 이동

2. 참석자 빠른 검색
   - 모임 관리 > 참석자·게스트에 닉네임 검색창 추가
   - 선택 인원 / 전체 활동회원 인원 표시

3. 모임 복사
   - 선택된 모임 또는 상세 팝업/모임 카드에서 복사 가능
   - 새 날짜만 입력
   - 제목 + 회원 참석자 목록 복사
   - 비용/게스트/특정값/선입금은 새 모임에서 새로 입력
   - 기존 모임의 정산 값을 실수로 복제하지 않도록 의도적으로 제외

4. 모바일 UX
   - 하단 고정 탭 네비게이션
   - 모임 상세는 모바일에서 바텀시트 형태
   - 헤더/검색/선택 모임 영역 반응형 개선

5. 데이터 안전성
   - 참석 해제 시 특정값 + 해당 모임 선입금 정리 기능은 Step 15 유지

적용 방법
- Step 15가 정상 적용된 상태에서
  app/page.tsx
  app/globals.css
  두 파일만 덮어쓰면 됩니다.
- 새로운 DB 테이블/SQL 변경 없음.

재시작
Ctrl + C
Remove-Item -Recurse -Force .\.next -ErrorAction SilentlyContinue
npm run dev
