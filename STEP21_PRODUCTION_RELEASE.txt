STEP 21 - 사용자 배포용 최종 정리

핵심 변경
- 제작자(owner)가 이미 존재하면 로그인 화면의 "초기 운영자 설정" 메뉴 자동 숨김
- DB 초기화 후 owner가 0명일 때만 초기 운영자 설정 메뉴 표시
- 최초 owner 지정 성공 즉시 설정키 입력값 삭제 + 메뉴 숨김
- 신규 회원 join_date를 Asia/Seoul 기준 날짜로 저장
- 전체 JSON 백업 버튼은 관리자/제작자에게만 표시
- 백업 JSON에서 profiles 데이터를 제외해 로그인 프로필 내부정보 노출 최소화
- PWA 서비스워커 캐시 버전을 v2로 갱신
- 기존 Step20 기능, 정산 공유, PWA, 대시보드, 통계 유지

추가 SQL 없음
추가 환경변수 없음

초기화 후 권장 순서
1. Supabase 테이블 데이터 초기화
2. Authentication > Users 기존 사용자 삭제
3. 배포 사이트 > 최초 가입으로 새 제작자 계정 생성
4. 로그인 화면 하단 "초기 운영자 설정"
5. CREATOR_SETUP_KEY + 제작자 닉네임 입력
6. 제작자 지정
7. 로그인
8. 다른 회원들이 최초 가입
9. 제작자 > 회원 현황에서 필요한 회원을 관리자 지정
10. 전체 기능 확인 후 URL 배포
