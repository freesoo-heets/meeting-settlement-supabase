STEP 33.2 - 회원현황 UX 레이아웃 재설계

스크린샷을 기준으로 기존 '회원 추가 + 회원 검색' 좌우 2카드 구조를 폐기했습니다.

새 구조:
1. 회원 현황 단일 카드
2. 상단 제목 + 관리자용 '+ 회원 추가' 버튼
3. 회원 추가는 평소 숨김, 버튼 클릭 시 펼침
4. 검색/정렬을 한 줄의 핵심 검색 영역으로 배치
5. 회원 상태를 4개의 넓은 요약 카드로 표시
6. 상태 카드 전체 영역을 클릭하여 필터 적용

집계:
- 전체 = 정상 활동중 + 경고
- 탈퇴는 전체에서 제외
- 탈퇴는 별도 필터 카드 유지

반응형:
- PC: 검색+정렬 1행 / 상태 4카드 1행
- 태블릿: 회원추가 폼 2열
- 모바일: 검색/정렬 1열 / 상태 2x2
- 작은 모바일: 회원추가 폼 1열

DB/환경변수 변경 없음
